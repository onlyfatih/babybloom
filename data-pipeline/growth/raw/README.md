# Raw official files

Filled by `python3 -I data-pipeline/growth/fetch_raw.py` on a network that
allows cdn.who.int, www.cdc.gov and ftp.cdc.gov. Files are committed as
downloaded, unchanged, with `MANIFEST.json` (sha256, size, URL, retrieval
time). Transformations read from here and never write here.

Empty as of 2026-11-27: the default cloud environment refuses these hosts.
